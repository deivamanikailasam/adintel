# AdIntel — Enterprise-Governed Agentic AI for Paid-Ad Intelligence

AdIntel is a team of AI agents that watches paid-ad performance for a marketing agency every
night, spots problems, works out why they happened, suggests fixes, and writes the client report.
**A human must approve anything that would spend client money.**

This repository is a **local-first** implementation: it runs entirely on your own machine using
two models served by `mlx-lm`, with a documented path to promote it to AWS production.
