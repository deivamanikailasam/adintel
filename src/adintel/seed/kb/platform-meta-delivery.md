# Meta delivery notes

## Budget changes and the learning phase
Large budget changes (more than about 20% to 30% at once) can push an ad set back into the learning phase,
temporarily raising CPA. Prefer changes of 25% or less and wait several days between changes.

## Advantage campaign budget
With campaign-level budgets, Meta decides how much each ad set gets. Ad-set spend limits are the main lever
when delivery drifts toward an inefficient audience.
