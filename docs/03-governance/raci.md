# RACI — who decides what

R = responsible, A = accountable, C = consulted, I = informed.

| Decision / activity | Sponsor (Head of Perf.) | Account managers | ML lead | Tech lead | Security | Legal |
|---------------------|:---:|:---:|:---:|:---:|:---:|:---:|
| Approve a recommendation (per matrix) | A (> $2k / high risk) | R | I | I | — | — |
| Change autonomy level (L2 → L3) | A | C | C | R | C | C |
| Change approval matrix / limits | A | C | I | R | C | I |
| Promote a model, adapter or prompt | I | I | A/R | C | C | — |
| Change brand constraints | C | R | I | A | — | — |
| Approve a procedural-memory rule (suppression) | I | R | C | A | — | — |
| Engage a kill switch | I | C | R | A | R | — |
| Respond to a P1 cross-tenant incident | I | I | C | R | A | R |
| Weekly eval triage | I | C | A/R | C | — | — |
| Client disclosure wording | C | C | C | C | C | A/R |
| Data retention / deletion requests | I | I | C | R | A | C |
