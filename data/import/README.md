# Bring your own data

Put CSV exports here as `<tenant_id>/<brand_id>/<platform>.csv` and run with `ADINTEL_CONNECTORS=csv`.
Platforms: `google_ads`, `meta`, `tiktok`, `linkedin`, `amazon_ads`. Header: `adintel csv-template`.
Worked example: `adintel csv-sample --brand urban-roast --period-end 2026-10-11`.

Everything in this folder except this README is git-ignored: it is client data.
